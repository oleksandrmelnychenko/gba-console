# Original Returns: current OUR Console binding

Isolated successor of accepted Console1761; backend contract is the separate
Returns delivery833f82. The original source identity/definition, four ordered
captions and Counterparty grouping are pinned in `data/managementReturns.ts`.
No existing form, native report launch, saved template or migration claim is removed.

The catalogue obtains genuine authenticated capabilities only after it is opened,
for the exact Source identity and caller. A missing/refused/unimplemented or
malformed capability remains disabled; there is no feature flag to assert readiness.
Availability checked by preview and native parity are separate. The same current
OUR variant remains accessible when the numeric native dataset list is unavailable.

The form offers current/previous local calendar windows, default current/prior
month. All four endpoints are editable `datetime-local` values. Start is included,
ThroughExclusive is excluded. Only calendar validation/canonical millisecond
formatting occurs in the browser; no local timezone conversion, native2007 date,
money calculation, ratio, rounding or FX conversion is introduced.

The preview uses the accepted session-bound stream API, unchanged. It captures
the real stored owner/CSRF generation, uses cookies/no-store and cancellation,
permits conventional same-owner401 refresh, and does not retry409, timeout or an
ambiguous successful write. The bounded reader accepts at most16MiB, matching the
existing native preview transport; it refuses oversized responses rather than
returning partial data. Request/result headers must exactly match the validated
body. Source identity, windows, policy/unit, ordered cells, actual monthly parent
vector, availability, UTC clocks and hashes are checked before values/files appear.

Financial values/exact evidence remain strings. Only server FormattedValue is
shown, with four original columns for totals and each opaque Counterparty group.
Actual server captions, confirmed Source NULL and unavailable names are distinct.
Missing names preserve valid arithmetic. No physical source refs, fractions or
private proof details are product labels. Management unit is explicitly
**Управлінська валюта**, with no invented EUR or FX mapping.

Complete empty, missing current/previous input and decimal projection overflow
have separate states. Both empty periods have four blank cells, with no invented
hundred or zero. Any caller, permission, capability or window change clears old
cells/downloads immediately and cancels the active request. A late response cannot
replace the new loading state or reopen old files. The XLSX/PDF links come from
the same server result; a missing PDF link leaves the primary workbook available.

Authored data/API/panel/launcher/workspace cases use production-shaped833f82 DTOs,
the real shared API stream/session module with mocked HTTP, and deferred caller
race/response drain cases. They are declarations only. Runtime tests, lint, build,
React Doctor, actual publication coverage and authenticated browser acceptance
are Root operations; none are claimed by this FILE/Git commit.

The dedicated routes are GET `/report/constructors/management-returns/capabilities`
and POST `/report/constructors/management-returns/preview`.

Static declarations comprise 55 cases across five test files: data 28 (seven
ordinary cases plus six calendar and 15 invalid-result expansions), API 12
(seven ordinary cases plus two header and three status expansions), panel nine,
catalogue launcher four and workspace two. The shared fixture is not a test file.
Actual executed counts and quality remain pending Root's current-tree run.
