# AI-аналітика товару — компактний екран

Обсяг: попап товару в «Весь асортимент» і його спільний ProductCard.

1. Компактний хедер: назва та артикул поруч, виробник синьою чіпсою. Загальна оцінка показана один раз у блоці оцінок.
2. Рекомендація в один адаптивний рядок. Поточні залишки, вартість, маржа й покриття окремою смугою, незалежною від історичного періоду продажів.
3. Один графік продажів: кількість, замовлення, виручка, середня ціна. Періоди 3/6/12 місяців фільтрують наявну 12-місячну відповідь API за календарем; змінюються графік, таблиця й підсумки. Середня ціна періоду зважена за кількістю.
4. Перемикач «Дані» показує точні значення місяців. Пропуски залишаються невідомими, реальний нуль збережено. Тренд використовує шість послідовних завершених місяців; вибір 3-місячного відображення не змінює базу порівняння 3 проти 3.
5. Службові абзаци замінено короткими позначками. Календарний діапазон видимий, дата зрізу й пояснення неповного місяця доступні у підказці.
6. Оцінки та комерційний профіль компактні й розкривні. Комерційний профіль зберігає окремі значення моделі; вони не підміняють фактичну історію продажів.
7. Білий/нейтрально-сірий фон, помаранчевий активний стан, спільні чіпси, моно в числах і контролах. Відступи 12px, проміжки контролів 6–8px; без персикової заливки графіка.

Спільні AnalyticsTabs/AnalyticsSeriesChart перенесені з feature закупівель до shared/ui/analytics; закупівлі використовують ті самі компоненти без зміни поведінки.

Перевірки: перемикання метрики й періоду, зважена середня ціна, неповні/відсутні/нульові дані, тренд і API-помилка; браузерний огляд реального товару й вузького екрана. Бізнес-оцінки та серверні рекомендації не перераховуються на клієнті.

Виконано. 39 цільових тестів пройшли, ESLint і production build успішні. У браузері перевірено реальний товар 73660CNT, перемикання періодів/метрик/таблиці та розкриття оцінок. На ширині 390px горизонтального переповнення немає. Для 3 місяців таблиця й підсумки збігаються: 460 одиниць, 7 замовлень, 287,31 EUR.
