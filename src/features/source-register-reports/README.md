# Register report components

This module provides controlled React components and an opt-in authorized host for register JSON profile v1. The reusable builder/table remain transport-free; the lazy `/reports/registers` host supplies descriptors, drafts and decoded statements through authenticated catalogue/schema/statement routes. There is no capture editor, publication/import/grant writer, persistence or built-in sample report. Existing report sources 0–16 retain their independent behavior.

Import components directly from `SourceRegisterReportBuilder` and `SourceRegisterResultTable`. Both require a host-supplied `registerLabel`; that label is presentation only. Use `emptyRegisterQueryDraft()` for new choices or `registerQueryDraft(query, descriptor)` to restore exact periods, axes and caller-selected order. The builder invokes `onChange` with editable query fields and `onSubmit` with the allowlisted query. The host controls loading, access and availability through `busy` and `disabled`.

Use `decodeRegisterSchema`, `decodeRegisterQuery` and `decodeRegisterStatement` from `registerJsonTransport` for original `Uint8Array` or `ReadableStream<Uint8Array>` input. Schema decoding requires an independently obtained exact schema key and original payload SHA256; statement decoding requires the independently expected query and full publication reference. Bindings must come from the trusted host integration, not from the response being checked. The decoder snapshots bytes and expected identities, checks strict UTF-8, decoded duplicate names, canonical tokens, depth 16 and byte ceilings before object validation. Statement preflight checks sparse and projected output budgets before constructing its complete object graph. There is no capture decoder.

The default statement limit is 32 MiB to match the runtime serving cap. `maximumBytes` can lower it or explicitly raise it up to the codec hard maximum 512 MiB; schema/query hard maxima are 2 MiB/128 KiB. Stream input is bounded before retention, with cancellation and no partial return; bytes supplied by a caller are necessarily already buffered, the authorized host uses the stream form directly at its fetch boundary. AbortSignal is observed while reading and at parser checkpoints; synchronous parsing does not promise main-thread preemption. Embedded query/metadata limits are 128 KiB/16 KiB. All limits include exact received UTF-8 bytes.

The host remains responsible for a trusted schema registry and publication/ACL authorization. The module also validates decoded object shapes, schema identity, typed groups, period coverage and exact operands. That structural validation does not authenticate a self-supplied publication reference. The opaque source schema hash is never derived from UI labels or the shortened descriptor DTO.

`serializeRegisterQuery` produces the versioned query only. Facts, completeness, principal policy and publication bindings cannot be submitted through it. Local time controls are formatted as seven-fraction source wall-clock strings without `Date` or timezone conversion. Incomplete draft controls remain editable; invalid periods cannot be submitted.

Numeric operands are canonical `{ coefficient: string, scale: string }` pairs. Formatting inserts a decimal comma textually and retains every digit; it performs no rounding, sums, currency conversion or floating point conversion. The result table displays sparse received groups and the authoritative grand values. Paging changes presentation only. It does not create missing intersections or additional totals. No chart conversion is provided.

Optional `referenceCaptions` maps full `registerAtomIdentity(atom)` to presentation text. Reference type, raw bytes and physical tags remain identity, even when captions match. Technical hashes and IDs appear in audit details; duplicate field captions show the full ID in selection choices to avoid ambiguous truncation.

The codec's `sourceParityVerified: false` remains visible. Source readiness, original ACL equivalence and actual publication availability belong to a separately approved integration. All `*.test-fixtures.ts` and `fixtures/` operands are synthetic test inputs, never live capability defaults.

The authorized host requires the existing report-generation permission and a loaded user identity. It bounds the catalogue to 16 MiB/4096 unique publications and obtains expected schema bytes SHA, schema key and publication bindings from that authenticated catalogue. An empty catalogue is shown as unavailable prepared data; no sample source appears. AuthorizationVersion distinguishes selected catalogue entries and is never submitted as a grant or query field.

The opt-in `shared/api/apiStreamClient` snapshots raw request bytes, headers and userNetUid/CSRF generation. Its separate guarded refresh promises never join another generation and recheck cancellation/generation before storage writes, retries and returned data. The host resets on logout, account change, permission loss or publication change; a normal same-user token refresh preserves the builder draft. A host-only stored-owner subscription also hides stale data after a cross-tab logout/account switch, without changing the global AuthProvider. Generation checks still reject late replies from a replaced same-user login. No report result survives a failed generation or draft edit.
